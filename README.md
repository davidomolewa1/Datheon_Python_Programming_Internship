# Datheon Python Programming Internship Portfolio 🚀

Welcome to my official project repository for the **Datheon Python Programming Internship**. This repository serves as a showcase of core programming principles, algorithmic design, and architectural problem-solving using Python 3.x. 

Each project is contained within its own dedicated subfolder, complete with individual source code files and specialized documentation.

---

## 📂 Repository Index & Navigation

### 1. [🤖 TechStore Support Assistant](./01_TechStore_Chatbot/)
A deterministic, rule-based customer support chatbot simulation. It handles incoming retail-oriented customer inquiries via regular expressions and pulls answers dynamically from a decoupled data schema.
*   **Key Concepts:** RegEx parsing, Input normalization, Decoupled dictionaries, Fallback handling.

### 2. [🎮 Hangman Word Guessing Game](./02_Hangman_Game/)
An advanced twist on the traditional Hangman word game. It introduces custom game-state logic that delibrately limits standard letter reveals to test strategic thinking.
*   **Key Concepts:** Random selection elements, State tracking arrays, Filtered scanning loops.

## 🛠️ Global Getting Started & Pre-requisites

### Requirements
*   **Python 3.x** must be installed on your local host system.
*   No external third-party dependencies or pip packages are required (built entirely using the Python standard library: `re`, `random`).

### Clone and Run
1. Clone this repository locally:
   ```bash
   git clone https://github.com/davidomolewa1/Datheon_Python_Programming_Internship.git
   ```
2. Change into the specific project directory you wish to use:
   ```bash
   cd 01_TechStore_Chatbot
   # OR
   cd 02_Hangman_Game
   ```
3. Follow the execution instructions found within that subfolder's respective `README.md` file.
